# EPIC-001: VoicePilot Investigation Engine

## Goal

Build the core investigation workflow that behaves like a senior TAC engineer.

## User Story

As a voice engineer, I want VoicePilot to guide me through an incident investigation so that I can find the root cause faster and with confidence.

## Scope

- Case creation
- Intake questions
- Topology capture
- Evidence collection
- Hypothesis tracking
- Confidence scoring
- Next-best-action selection
- Resolution and verification
